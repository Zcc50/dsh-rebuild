# A6.02 情绪放大

## 一句话

轻微事件引发远超比例的强烈反应，像音量旋钮坏了。

## 现象

小事引发大哭或暴怒；事后知道"不至于"但当时就是那么大；恢复慢。

## 症状条目

- [ ] 对轻微刺激反应强度远超事件本身
- [ ] 反应来得快
- [ ] 恢复时间长（远超事件持续时间）
- [ ] 事后有"反应过度"的自觉
- [ ] 常因此破坏关系或工作
- [ ] 旁人评价"太敏感"

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | ≥ 2 周 |
| 频率 | ≥ 每周 2 次 |
| 影响 | 关系或工作受影响 |

## 常见伴随

- A6.01 情绪快速切换
- A3.01 爆发型暴怒
- C 创伤与应激

## 区分要点

- **与 A6.01**：放大是"强度"问题，切换是"频率"问题。放大可以只发生一次，切换一定是多次。
- **与创伤触发**：若反应由特定线索（声音、气味、姿态）触发，优先记 C 类；无特定线索的过度反应记 A6.02。
- **与高敏感人格特质**：特质是长期稳定的，能追溯很多年；A6.02 是"某段时间内的变化"，有起点。

## 相关因素

睡眠不足、压力累积、激素周期、未处理的情绪堆积。

## 边界提示

- 已造成重要关系损伤
- 反应中出现攻击行为

## 记录字段

日期 / 编号 / 强度 0–10 / 持续 / 诱因标签 / 备注（备注里写"事件大小"与"反应强度"的对比）。

## 统计口径

进强度统计（重点看"事件大小 vs 反应强度"的落差，备注里标注）。
