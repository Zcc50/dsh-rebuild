# C1.01 创伤后应激反应

## 一句话

经历或目睹重大事件后，出现的一整套反应：侵入、回避、警觉、麻木。

## 现象

反复想起；避开相关场合；睡不着；容易惊；感觉和世界隔了一层；对以前在意的事失去兴趣。

## 症状条目

- [ ] 有明确的创伤事件（亲历、目睹、得知）
- [ ] 反复的侵入性回忆或噩梦
- [ ] 回避与事件相关的场合、人、话题
- [ ] 过度警觉、易惊跳
- [ ] 情绪麻木、疏离
- [ ] 负性信念（"世界不安全""我完了"）
- [ ] 症状持续 ≥ 1 个月

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | ≥ 1 个月 |
| 频率 | 几乎每天有侵入或警觉 |
| 影响 | 工作、关系、睡眠至少一项受影响 |

## 常见伴随

- C2.01 闪回
- C3.01 情境回避
- C4.01 过度警觉（创伤性）
- C5.01 情感麻木

## 区分要点

- **与 C1.02 急性应激反应**：时间窗不同，这条 ≥ 1 个月。
- **与 B1.01 自由浮动的焦虑**：那条没有明确事件，这条有。

## 相关因素

事件的强度、是否有支持、既往创伤史、事件后是否被否定。

## 边界提示

- 症状持续超过 1 个月且影响功能
- 出现自伤念头或严重解离

## 记录字段

日期 / 编号 / 强度档 / 持续档 / 诱因 / 场景 / 应对 / 备注（可选）。

## 统计口径

进频次与强度统计；备注里写"事件发生多久了"。
