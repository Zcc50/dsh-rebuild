# C6.02 持续负性情绪

## 一句话

恐惧、愤怒、内疚、羞耻，长期挂着，不随事件结束而消退。

## 现象

底色一直是紧绷的；容易愤怒；有说不出的内疚；难以体验积极情绪；偶尔又突然暴躁。

## 症状条目

- [ ] 持续的恐惧或警觉
- [ ] 持续的愤怒或易激惹
- [ ] 持续的内疚或羞耻
- [ ] 难以体验积极情绪
- [ ] 情绪来得突然、强度大

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | ≥ 1 个月 |
| 频率 | 几乎每天 |
| 影响 | 关系或日常功能受影响 |

## 常见伴随

- C6.01 负面自我信念
- C1.01 创伤后应激反应
- A3 易怒与愤怒

## 区分要点

- **与 A1.01 低落**：低落以"低"为主；这条是多种负性情绪混合，且与事件相关。
- **与 A6.02 情绪放大**：放大是"反应强度"问题；这条是"底色长期负性"。

## 相关因素

事件未处理、持续压力、缺乏支持。

## 边界提示

- 负性情绪长期不退且影响功能
- 伴随自伤念头

## 记录字段

日期 / 编号 / 强度档 / 持续档 / 诱因 / 场景 / 应对 / 备注（可选）。

## 统计口径

进频次与强度统计；备注里区分主要情绪（恐惧/愤怒/内疚/羞耻）。
