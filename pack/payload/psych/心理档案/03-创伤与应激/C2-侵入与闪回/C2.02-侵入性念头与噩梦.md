# C2.02 侵入性念头与噩梦

## 一句话

不想它的时候它自己进来；睡着了也躲不开。

## 现象

不自主出现与事件相关的念头；噩梦；试图压下去反而更频繁；影响入睡；白天被突然打断。

## 症状条目

- [ ] 不自主出现与事件相关的念头
- [ ] 噩梦，内容与事件相关
- [ ] 试图压下去但更频繁
- [ ] 影响入睡或睡眠质量
- [ ] 白天被突然打断，注意力中断

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | ≥ 2 周 |
| 频率 | 几乎每天 |
| 影响 | 睡眠或专注受影响 |

## 常见伴随

- C2.01 闪回
- C1.01 创伤后应激反应
- H 睡眠与节律

## 区分要点

- **与 B5.01 担忧反刍**：反刍是主动去想的循环（越想越焦虑）；侵入是被动的闯入（不想也来）。
- **与 C2.01 闪回**：闪回是整段体验重演；这条是片段式（念头、画面、梦）。

## 相关因素

睡眠不足、压力、触发线索。

## 边界提示

- 噩梦频繁且影响白天功能
- 伴随明显的回避行为

## 记录字段

日期 / 编号 / 强度档 / 持续档 / 诱因 / 场景 / 应对 / 备注（可选）。

## 统计口径

进频次统计；备注里区分"念头"还是"噩梦"。
