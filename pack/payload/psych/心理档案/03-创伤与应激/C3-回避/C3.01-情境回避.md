# C3.01 情境回避

## 一句话

绕开一切可能让你想起那件事的东西。

## 现象

不去某些地方；避开某些人；不看相关内容；不参加某些活动；回避范围慢慢扩大。

## 症状条目

- [ ] 主动避开与事件相关的地点、人、话题
- [ ] 回避已影响日常安排
- [ ] 回避范围在扩大
- [ ] 想到要面对就焦虑或紧张
- [ ] 为自己找理由解释回避

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | ≥ 2 周 |
| 频率 | 持续存在 |
| 影响 | 日常活动范围收缩 |

## 常见伴随

- C1.01 创伤后应激反应
- C3.02 情感回避

## 区分要点

- **与 B3.02 恐惧性回避**：那条回避的是"特定恐惧对象"；这条回避的是"与事件相关的任何线索"。
- **与正常的偏好**：正常偏好不影响功能；回避是让渡了生活空间。

## 相关因素

事件相关线索的普遍程度、社会压力。

## 边界提示

- 回避范围明显扩大
- 影响工作、就医、出行

## 记录字段

日期 / 编号 / 强度档 / 持续档 / 诱因 / 场景 / 应对 / 备注（可选）。

## 统计口径

进频次统计；备注里记"回避了什么、放弃了什么"。
