# G5.02 强迫性仪式

## 一句话

某些动作必须按顺序做，否则不安。

## 现象

固定顺序；被打断要重来；耗时；明知没必要但停不下来。

## 症状条目

- [ ] 某些动作必须按固定顺序做
- [ ] 被打断需要重来
- [ ] 不做会强烈不安
- [ ] 仪式占用明显时间
- [ ] 明知过度但停不下来

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | ≥ 2 周 |
| 频率 | 几乎每天 |
| 影响 | 时间或情绪受影响 |

## 常见伴随

- G5.01 强迫性检查
- B1.01 自由浮动的焦虑

## 区分要点

- **与习惯**：习惯被打断无所谓；这条被打断会强烈不安。
- **与 G5.01**：一个是动作，一个是确认。

## 相关因素

焦虑、对失控的恐惧、压力期。

## 边界提示

- 仪式占用大量时间
- 影响到正常生活

## 记录字段

日期 / 编号 / 强度档 / 持续档 / 诱因 / 场景 / 应对 / 备注（可选）。

## 统计口径

进频次统计；备注里写"什么动作、花了多久"。
