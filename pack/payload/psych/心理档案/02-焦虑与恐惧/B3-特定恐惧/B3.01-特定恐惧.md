# B3.01 特定恐惧

## 一句话

对某个具体对象或场景的强烈恐惧，明知道过度但控制不住。

## 现象

怕高、怕虫、怕血、怕封闭空间、怕打针；遇到就想逃；知道不合理但身体先反应了。

## 症状条目

- [ ] 对特定对象或场景有强烈恐惧
- [ ] 接触时立即出现焦虑反应（心跳、出汗、僵住）
- [ ] 知道反应过度，但控制不住
- [ ] 会主动回避
- [ ] 光是想到就会紧张

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | 单次接触即可记录 |
| 频率 | 出现即记 |
| 影响 | 回避行为影响了日常安排 |

## 常见伴随

- B3.02 恐惧性回避
- B6.01 躯体紧张

## 区分要点

- **与 B4 社交焦虑**：那条针对"被评价"，这条针对"对象本身"。
- **与 C 创伤触发**：若恐惧与某次具体创伤事件绑定，优先记 C 类。

## 相关因素

直接的惊吓经历、目睹他人受伤、家族倾向。

## 边界提示

- 恐惧对象是就医、驾驶等必要场景，已影响生活
- 回避范围扩大

## 记录字段

日期 / 编号 / 强度档 / 持续档 / 诱因 / 场景 / 应对 / 备注（可选）。

## 统计口径

进频次与强度统计；备注里写"恐惧对象"（便于归类）。
