# B1.02 过度警觉

## 一句话

对周围的风吹草动都比平时敏感，像雷达一直开着。

## 现象

容易被声音惊到；在人群里很快累；总在扫视环境；别人的表情变化被放大解读；睡眠浅。

## 症状条目

- [ ] 对声音、动作、表情异常敏感
- [ ] 容易惊跳
- [ ] 在人多的环境里很快耗尽精力
- [ ] 总在"扫"环境，找可能的威胁
- [ ] 睡眠浅、易醒、醒了难再睡

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | ≥ 2 周 |
| 频率 | 几乎每天 |
| 影响 | 社交或工作场合的消耗明显增加 |

## 常见伴随

- B1.01 自由浮动的焦虑
- A6.02 情绪放大
- C 创伤与应激（若与特定线索绑定，优先记 C 类）

## 区分要点

- **与 C 类创伤后过度警觉**：C 类通常与特定线索绑定（声音、气味、姿态），有明确触发源；这条更弥散，不指向具体事件。
- **与 B1.01**：B1.01 是"心里悬着"，这条是"感知变灵敏"，是同一状态的两个切面。

## 相关因素

睡眠剥夺、咖啡因、长期高压、创伤史。

## 边界提示

- 影响到出门、上班、社交
- 伴随明显的心悸、手抖
