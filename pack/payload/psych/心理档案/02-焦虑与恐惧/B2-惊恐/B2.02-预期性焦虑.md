# B2.02 预期性焦虑（怕再发）

## 一句话

怕它再来，于是开始躲、开始检查、开始不敢去某些地方。

## 现象

反复想"会不会又发作"；避开上次发作的场合；随身带药或水；身体一有风吹草动就紧张；回避范围慢慢扩大。

## 症状条目

- [ ] 反复担心再次发作
- [ ] 回避上次发作的地点或情境
- [ ] 过度检查身体信号
- [ ] 为"安全"做准备（带药、带水、选靠门座位）
- [ ] 回避范围逐渐扩大

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | ≥ 2 周 |
| 频率 | 几乎每天 |
| 影响 | 活动范围收缩，或日常安排被改变 |

## 常见伴随

- B2.01 惊恐发作
- B3.02 恐惧性回避
- B1.01 自由浮动的焦虑

## 区分要点

- **与 B3.02 恐惧性回避**：那条回避的是"具体对象"（高、虫、电梯）；这条回避的是"发作本身"。
- **与正常谨慎**：正常谨慎不影响生活范围；这条会让活动范围持续收缩。

## 相关因素

一次强烈发作之后、睡眠不足、压力期。

## 边界提示

- 回避范围持续扩大（例如从"不坐地铁"扩到"不出门"）
- 影响到工作或就医

## 记录字段

日期 / 编号 / 强度档 / 持续档 / 诱因 / 场景 / 应对 / 备注（可选）。

## 统计口径

进频次与强度统计；备注里记"本次回避了什么"，用于统计回避范围变化。
