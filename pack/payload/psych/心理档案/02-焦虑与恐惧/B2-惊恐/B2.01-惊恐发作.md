# B2.01 惊恐发作

## 一句话

突然的、强烈的恐惧高峰，几分钟内到顶，伴随强烈的身体反应和"要死了 / 要疯了"的感觉。

## 现象

突然心跳加速、出汗、发抖、喘不上气；觉得自己要死或失控；通常在 10–20 分钟内达峰，然后慢慢退；发作后极度疲惫。

## 症状条目

- [ ] 突然发作，无预警或只有轻微诱因
- [ ] 心跳加速、胸闷、窒息感
- [ ] 头晕、发抖、出汗
- [ ] 濒死感或失控感
- [ ] 发作后极度疲惫
- [ ] 发作时有"这不正常"的强烈感觉

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | 单次即可记录；通常 10–20 分钟内达峰 |
| 频率 | 出现即记；每月 ≥ 1 次进统计 |
| 影响 | 发作后需要时间恢复 |

## 常见伴随

- B2.02 预期性焦虑
- B6.01 躯体紧张
- A6.02 情绪放大

## 区分要点

- **与一般焦虑**：焦虑是持续的、渐进的；惊恐发作有明确的起止，强度极高。
- **与心脏问题**：首次发作且伴胸痛、晕厥、持续不缓解，先排查躯体原因，不要直接归为心理。

## 相关因素

咖啡因、睡眠剥夺、低血糖、酒精戒断、应激事件。

## 边界提示

- 首次发作，伴随胸痛 / 晕厥 / 持续不缓解 → 先就医排查
- 发作频率上升，或开始因此回避出门

## 记录字段

日期 / 编号 / 强度档 / 持续档 / 诱因 / 场景 / 应对 / 备注（可选）。

## 统计口径

进频次与强度统计；单独统计"发作间隔"（看是否变密）。
