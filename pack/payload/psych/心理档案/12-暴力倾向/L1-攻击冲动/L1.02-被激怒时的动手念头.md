# L1.02 被激怒时的动手念头

## 一句话

被具体的人或事点着之后，脑子里出现"打回去"的选项。

## 现象

争执中被顶一句，脑子里闪过一拳过去；被冒犯时手已经攥紧；念头出现得快，通常没做；有的持续到事后还在回放。

## 症状条目

- [ ] 被顶撞、被冒犯后出现"动手"的念头
- [ ] 伴随身体反应（握拳、心跳快、脸热）
- [ ] 念头和"要不要做"的判断同时出现
- [ ] 事后仍会回放那个场景

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | 单次几秒到几小时 |
| 频率 | 每周 ≥ 1 次 |
| 影响 | 影响关系、睡眠或后续状态 |

## 常见伴随

- A3.01 爆发型暴怒
- A3.02 慢性易激惹
- L5.02 报复性想象

## 区分要点

- **与 L1.01 突发攻击冲动**：那条找不到由头；这条由具体事件点着。
- **与 A3.02 慢性易激惹**：那条是长期底火、没有峰值；这条有明确的触发点和念头。

## 相关因素

人际冲突、被否定、累积的委屈、疲劳。

## 边界提示

- 念头反复指向同一个具体的人
- 开始出现"什么时候"的打算

## 记录字段

日期 / 编号 / 强度档 / 持续档 / 诱因 / 场景 / 应对 / 备注（可选）。

## 统计口径

进频次与强度统计；与 A3.01、A3.02 做共现分析。
