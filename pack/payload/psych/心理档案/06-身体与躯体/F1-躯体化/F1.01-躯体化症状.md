# F1.01 躯体化症状

## 一句话

情绪变成身体症状，检查查不出明确原因。

## 现象

头痛、胃痛、胸闷、乏力；反复检查无异常；医生说"没事"但确实难受；越关注越明显。

## 症状条目

- [ ] 反复出现身体不适（头痛、胃痛、胸闷等）
- [ ] 医学检查未见明确异常
- [ ] 症状随压力或情绪变化
- [ ] 越关注越明显
- [ ] 因症状反复就医

## 判据

| 维度 | 门槛 |
|---|---|
| 持续时间 | ≥ 2 周 |
| 频率 | 几乎每天 |
| 影响 | 日常活动或注意力受影响 |

## 常见伴随

- B6.01 躯体紧张
- F1.02 症状与情绪同步

## 区分要点

- **与真实的躯体疾病**：先排查。这条的特征是"检查无异常 + 随情绪波动"。
- **与 B6.01**：B6.01 集中在焦虑的躯体表现；这条更泛，可涉及各个系统。

## 相关因素

压力、睡眠不足、焦虑、抑郁。

## 边界提示

- 症状突然加重或出现新症状 → 先就医
- 因反复检查消耗大量精力

## 记录字段

日期 / 编号 / 强度档 / 持续档 / 诱因 / 场景 / 应对 / 备注（可选）。

## 统计口径
