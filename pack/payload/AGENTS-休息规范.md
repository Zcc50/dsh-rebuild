# 休息规范（AGENTS 附件）

> 由 `AGENTS.md` 第⑨条引用；只在用户口头说「休息」时加载。
> 主文件：`AGENTS.md`（操作白皮书）。

## 第⑨条 休息（强制）

- **触发条件**：用户口头说「休息」（或同义说法）时触发；不自动计数、不设档位。

- **固定动作（命中即按序执行）**：
  1. **回应**：在回复中写一行「休息中」确认收到指令；
  2. **更新任务列表**：已完成的标完成、进行中的写清下一步、新需求补父任务，全部落 `task_edit`（整体替换才用 `task_write`）；
  3. **回看进度**：一句话说清「做到哪、下一步是什么」；
  4. **判断去留**：当前工作过于冗长或已陷入不必要的思考时，结束本轮回答——收尾、直接给结论，不追加探索；仍有必要则继续推进；
  5. **不结束会话**：休息不是终止；判定「继续」后立即接着干，不重复走休息流程。
- **证据**：用户休息指令 + 任务列表更新 + 「结束本轮 / 继续」的判定结论，三者齐备才算执行过本条。
